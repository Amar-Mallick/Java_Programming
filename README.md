# Java Programming ☕

Welcome to my Java Programming repository! This space is dedicated to exploring Core Java concepts, practicing coding problems, and building a strong programming foundation. 

Core Java concepts and practice codes are available here, serving as a personal knowledge base and a showcase of my continuous learning journey.

## 📚 Topics Covered

This repository includes examples, practice codes, and notes for various Core Java topics, such as:
* **Fundamentals:** Data types, Variables, Operators, Control Flow Statements (Loops, If-Else).
* **Object-Oriented Programming (OOP):** Classes, Objects, Inheritance, Polymorphism, Abstraction, and Encapsulation.
* **Data Structures & Collections:** Arrays, Lists, Sets, Maps, and the Java Collections Framework.
* **Exception Handling:** Try-catch blocks, custom exceptions.
* **Strings:** String manipulation, StringBuilder, StringBuffer.
* **File I/O:** Reading from and writing to files.

## ⚙️ Prerequisites

To compile and run the code in this repository, ensure you have the following installed:
* [Java Development Kit (JDK)](https://www.oracle.com/java/technologies/downloads/) (Version 8 or higher)
* An IDE of your choice (e.g., [IntelliJ IDEA](https://www.jetbrains.com/idea/), [Eclipse](https://www.eclipse.org/downloads/), or [VS Code](https://code.visualstudio.com/))
